# Patchling’s Quest

October 7, 2026. The parent selected this direction after finding the earlier subtitle too plain and Worldwake too much like an expansion. Use **Patchling’s Quest** for the public 2D title and **Patchling** for the compact installed-app label.

Patchling is a small walking coat stitched from an old road map. The quest is to help neighbours reopen the roads, learn useful shapes and wake the Worldbearers. The name puts the approachable hero first, uses familiar pronounceable words, and works as a single adventure title. “A little coat. A world to mend.” remains the title-screen line.

## Design use

Prefer adventures where a shape helps a person and visibly changes the route. A bridge, ferry or lamp should look different after the action, remain useful on a return visit, and give its neighbour something specific to celebrate. Bramblebank, Reedbed Ferry, Copperwick Lampyard, Rainbell Steps and Hearthside Turn apply this direction. See [EARLY-FORM-ROADS.md](EARLY-FORM-ROADS.md).
