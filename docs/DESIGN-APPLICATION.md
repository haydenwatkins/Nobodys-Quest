## Delivery rule

Every future gameplay batch names the principles it advances, the existing content it backfills, the shared mechanisms it changes and the remaining authored gaps. Inspect this compact ledger and the active roadmap before choosing work. Revise priorities when family feedback supplies a stronger need, without deleting earlier obligations. Use focused tests first and full regression at shared integration checkpoints; write accurate evidence after completion.
